# GenGhealth Interactive Pitch Deck

A premium, interactive web-based pitch presentation designed specifically for the **GenGhealth** mobile application. Built using clean, modern HTML5, Vanilla CSS, and JavaScript.

## Features

- **Branded Design**: Seamlessly aligns with the GenGhealth visual system (Slate Dark `#0F172A`, Emerald Green `#10B981`, and vibrant background glow overlays).
- **Responsive Layout**: Adapts gracefully to all screen sizes, optimizing for desktop projectors, laptops, tablets, and phones.
- **Aspect Ratio Control**: Best viewed on 16:9 widescreen displays.
- **Flexible Navigation**:
  - **Keyboard**: Use `ArrowRight`, `Spacebar`, or `Enter` to advance. Use `ArrowLeft` or `Backspace` to go back.
  - **Clicks/Taps**: Click the bottom dots directly to jump to slides, or tap the prev/next arrow controls.
  - **Touch Swipe**: Swipe left or right on touchscreen monitors or mobile devices to switch slides.
- **Interactive Controls**:
  - Fullscreen toggle in the bottom right corner.
  - Automatic progress indicators.

## Running the Presentation

To view the pitch deck, simply open the `index.html` file in any modern web browser:

1. Right-click [index.html](file:///d:/geng_health/marketing/pitch-deck/index.html) and open it with Google Chrome, Microsoft Edge, Firefox, or Safari.
2. Or run a local development server from the repository root:
   ```bash
   npx serve marketing/pitch-deck
   ```
